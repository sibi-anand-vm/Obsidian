1.Have Initial Git config in CLI
```
git config --global user.name "sibi-anand-vm"
git config --global user.email "sibianand.vm2022ece@sece.ac.in"
git config --global push.default simple
git config --global alias.co checkout
git init
```
2.Add files to staging area
```
git add .
```
3.Add commit
```
git commit -am "Initial commit"
```
4.Push files to remote repository(Example Remote Repository URL is used)
```
git remote add origin https://github.com/sibi-anand-vm/Django-CRM.git
```
5.Rename initial branch name to main:
```
git branch -M main
```
6..Push by below cmd:
```
git push -u origin main
```
