1.Lets create a model for DB by following code in website's **model.py**:
```
from django.db import models
class File(models.Model):
	created_at=models.DateTimeField(auto_now_add=True)
	username=models.CharField(max_length=50)
	first_name=models.CharField(max_length=50)
	last_name=models.CharField(max_length=5)
	email=models.CharField(max_length=100)
	address=models.CharField(max_length=150)
	state=models.CharField(max_length=50)
	pincode=models.IntegerField()
	def __str__(self):
		return(f"{self.username}")
```

"__str__" func() in python:
```
person = Person('John', 'Doe', 25) 
print(person)
```
Output:
```
<__main__.Person object at 0x0000023CA16D13A0>
```
But __str__() allows you to print string representation of instance by:
```
def __str__(self): return f'Person({self.first_name},{self.last_name},{self.age})'
```
