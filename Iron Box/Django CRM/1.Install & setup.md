1.Create virtual environment
```
python -m venv virt
```
2.Turn on virtual environment
```
source virt/bin/activate
```
3.Install Django and MySQL
```
pip install django
```
```
pip install mysql
```
4.Install MySQL connector
```
pip install mysql-connector
```
5.Download MySQL Server
```
sudo apt install mysql-server
```
6.Check MySQL Running status:
```
sudo systemctl status mysql.service
```
7.Start MySQL server if not running.
```
sudo systemctl start mysql.service
```
8.Login MySQL:
```
sudo mysql -u root -p
```
9.Create Django Project
```
django-admin startproject <projectname>
```
Example:
```
django-admin startproject dcrm
```
10.Navigate to project folder and create an app:
```
cd <projectfolder>
python manage.py startapp <appname>
```
Example:
```
cd dcrm
python manage.py startapp website
```
