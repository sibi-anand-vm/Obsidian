1.Create a separate page for each individual file by creating new URL pattern in **urls.py**
```
path('file/<int:pk>',views.cus_file,name='file')
```
![[Pasted image 20241224183133.png]]
2.Create an **cus_file** func in  views.py with below code:
```
if request.user.is_authenticated:
	cus_file=File.objects.get(id=pk)
	return render(request,'file.html',{'cus_file':cus_file})
else:
	messages.success(request,"You need to logged in")
	return redirect('home')
```
![[Pasted image 20241224183313.png]]
3.Lets create **file.html** in templates folder and add some code show individual customer file in web-page:
```
{% extends 'base.html' %}
{% block content %}

<div class="col-md-6 offset-md-3">
<h1>Customer File</h1><br>

{{ cus_file.email }}<br>
{{ cus_file.address }}<br>
{{ cus_file.state }}<br>
{{ cus_file.pincode }}
</div>
{% endblock %}
```

4.Add URL to each customer file by adding URL in **a** tag with **href attribute** of each file in **home.html**.
```
<th scope="row"><a href="{% url 'file' file.id %}"> {{file.id }}</a></th>
```
