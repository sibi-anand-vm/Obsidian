2.Change the functionality of **home** function views.py in **website** folder like below:
```
from django.shortcuts import render,redirect
from django.contrib.auth import authenticate,login,logout
from django.contrib import messages
def home(request):
	if request.method=="POST":
		username=request.POST['Username']
		password=request.POST['Password']
		user=authenticate(request,username=username,password=password)
		if user is not None:
			messages.success(request,"You logged In")
			return redirect('home')
		else:
			messages.success(request,"There is some problem.Please Try again...")
			return redirect('home')
	else:	
		return render(request,'home.html',{})
```

(ii) Credentials Validated by **authenticate** function.
(iii) **Alert messages** will be sent and **Pages** redirected based on Authentication.
