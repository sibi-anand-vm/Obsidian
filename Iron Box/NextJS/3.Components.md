## <font color="#9bbb59">Lets Create an Server component called Greet by follow:</font>
1.First create an components folder inside <font color="#8db3e2">**src**</font> folder with files <font color="#fac08f">Counter.js and Greet.js</font>
```
//Counter.js
import {useState} from 'react';
const Counter=()=>{
const [count,setcount]=useState(0);
return <button onClick={()=>setcount(count+1)} >Clicked {count} times</button>
}
export default Counter;
```

While importing Counter component in <font color="#fac08f">**page.tsx**</font>,make sure to add "use client" in top of file for mentioning client component

2.Create Greet component and use in <font color="#fac08f">**page.tsx**</font> file.
```
const Greet=()=>{
console.log("From greet");
return <h1>Greet Component</h1>
}
export default Greet;
```
