## <font color="#4bacc6">Dynamic Routing</font>

To make dynamic routing,create folder with name like <font color="#ff0000">**[id]**</font>
For example:
![[Pasted image 20250201002521.png]]
```
//page.tsx
export default async function Product({params}:{params:{id:string}}){
const {id}=await params;
return <h1>Product:{id}</h1>
}
```

## <font color="#4bacc6">Wrapped Routing</font>
In Next.js (App Router), folders wrapped in parentheses `()` are **ignored routes**. These folders do not affect the URL structure but help with organising files.
![[Pasted image 20250201003359.png]]
### Use Cases:

1. **Grouping Without Affecting URL**  
    Useful for organizing files without changing the route structure.
    
2. **Layouts Without Adding a Route Segment**  
    You can add a `layout.tsx` inside the `(group)` folder to wrap pages with a layout without affecting the route.
