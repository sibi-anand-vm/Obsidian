Lets create an <font color="#4bacc6">layout.tsx</font> file in <font color="#ff0000">products/[id]</font> folder
![[Pasted image 20250202165611.png]]

Add the following code in it.
```
export default function ProductLayout({
children,
}:{children:React.ReactNode})
{
return(
<div>
{children}
<div>
Featured products
</div>
</div>
)
}
```

Now the text <font color="#fac08f">Featured products</font> Line will appear on Bottom of content in <font color="#fac08f">products/[id]</font> folder content.
