### **`usePathname` vs `useRouter` in <font color="#e5e0ec">Next.js </font>(App Router)**

Both `usePathname` and `useRouter` are used for navigation , but they serve different purposes.

---

### **1️⃣ `usePathname` (from `next/navigation`)**

- Used **only** to get the current route path name.
- **Read-only** → Cannot navigate with it.
- Useful for **conditionally styling navigation links** or checking the active route.

#### **Example (`usePathname`)**
```
//Navigation.js in Components folder
"use client";
import Link from "next/link";
import { usePathname } from "next/navigation";

export default function Navigation() {
const pathname = usePathname();

return (
<nav>

<Link href="/" className={pathname === "/" ? "font-bold mr-4" : "mr-4 text-blue-500"}>Home</Link>
<Link href="/about" className={pathname === "/about" ? "font-bold mr-4" : "mr-4 text-blue-500"}>About</Link>
<Link href="/Login" className={pathname === "/login" ? "font-bold mr-4" : "mr-4 text-blue-500"}>Login</Link>
<Link href="/product/1" className={pathname?.startsWith("/product/") ? "font-bold mr-4" : "mr-4 text-blue-500"}>Products</Link>
</nav>

);
}
```

### **2️⃣ `useRouter` (from `next/navigation`)**

- Used for **programmatic navigation** (i.e., navigating without `<Link>`).
- Provides methods like:
    - `router.push('/path')` → Navigate to a new page.
    - `router.replace('/path')` → Replace current history entry.
    - `router.back()` → Go back.
#### **Example (`useRouter`)**
```
//page.tsx in About folder
"use client"
import { useRouter } from "next/navigation";

export default function About(){
let router=useRouter();
return (
<>
<h1>About</h1>
<button onClick={()=>router.push('/')}>Go Home</button>
</>
);
}
```
