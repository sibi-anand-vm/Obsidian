
### **Projects**

🔹 **Video Streaming Platform**  
A full-stack **MERN-based movie streaming website** that allows users to register, log in, and watch movies stored securely on Google Drive.

- Implemented **JWT-based authentication** and **CryptoJS** to protect video URLs and user data.
    
- Integrated features such as **movie categorization**, a **responsive UI**, and **smooth playback experience**.
    
- Focused on delivering a **clean, intuitive interface** and ensuring **cross-device compatibility**.  
    **Tech Stack**: MongoDB, Express.js, React.js, Node.js, JWT, CryptoJS, REST APIs
    

🔹 **Customer Relationship Management (CRM) System**  
Designed and developed a **CRM web application** using **Django and MySQL** to manage customer information efficiently.

- Enabled **CRUD operations** with secure data handling using **Django ORM**.
    
- Incorporated **authentication and role-based access control** to ensure data privacy.
    
- Built a **responsive dashboard** with Django templates and Bootstrap for better user interaction.  
    **Tech Stack**: Django, MySQL, HTML/CSS, Bootstrap, Django Templates, Django ORM
    

🔹 **Sports Event Organizer**  
A desktop-based event management system built with **JavaFX** and **SceneBuilder**, aimed at helping users **plan, track, and explore events** effectively.

- Created an engaging UI that enables users to **register events, view schedules**, and **manage participant data**.
    
- Used **MySQL** for backend storage, ensuring fast and reliable data access.
    
- Enhanced user experience through a **visually appealing interface** and smooth event management flow.  
    **Tech Stack**: Java, JavaFX, SceneBuilder, MySQL
