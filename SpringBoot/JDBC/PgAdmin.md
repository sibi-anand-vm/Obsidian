# A) Do it with the GUI (no SQL)

### 1) Connect & select your DB

- Open **pgAdmin 4** → connect to your server.
    
- Expand **Servers → PostgreSQL → Databases** and **select your database** (e.g., `postgres` or your own).    
### 2) Create a table

- Expand **Schemas → public → Tables**.
    
- Right-click **Tables → Create → Table…**
    
- **General tab**
    
    - _Name_: `students` (example)
        
- **Columns tab** → click **+** to add columns:
    
    1. `id`
        
        - _Datatype_: `integer`
            
        - _Identity?_ Choose **Generated by default as identity** (auto-increment)
            
        - _Primary key_: **Yes** (tick the key icon)
            
    2. `full_name` → `varchar(100)` → _Not Null_: **Yes**
        
    3. `email` → `varchar(120)` → _Not Null_: **Yes**
        
    4. `enrolled_on` → `date` → _Default_: `CURRENT_DATE` (optional)
        
- Click **Save**.
### 3) Insert rows (grid editor)

- Right-click your new table **students** → **View/Edit Data → All Rows** (or “First 100 Rows”).
    
- Click the **pencil** (edit) → use the **last empty row** to enter data:
    
    - Example rows:
        
        - `full_name`: Alice Kumar | `email`: alice@example.com | `enrolled_on`: (leave blank to use today)
            
        - `full_name`: Bob Singh | `email`: bob@example.com | `enrolled_on`: 2025-09-02
            
- Click **Save** (disk icon). The `id` will auto-fill.
    
### 4) Verify

- In the data grid, hit the **refresh** icon, or run:
    
    - Right-click table → **Query Tool** → `SELECT * FROM public.students;` → **Execute** (▶)

# B) Do it with SQL (fast path)

If you prefer one-and-done SQL:

1. Open **Query Tool** (right-click DB → **Query Tool**), paste and run:
```sql
--1) Create table
CREATE TABLE public.students (
  id          integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  full_name   varchar(100) NOT NULL,
  email       varchar(120) NOT NULL UNIQUE,
  enrolled_on date DEFAULT CURRENT_DATE
);

-- 2) Insert data
INSERT INTO public.students (full_name, email, enrolled_on) VALUES
('Alice Kumar', 'alice@example.com', DEFAULT),
('Bob Singh',   'bob@example.com',   DATE '2025-09-02');

-- 3) Check
SELECT * FROM public.students;

```
